## Save hand-read (corrupt saves, web storage)
- **Bug found and fixed here:** a save with a wrong-typed field (e.g. `"tier":[1]`, `"stats":5`) made `Meta.from_dict` hit `int(Array)`, a script error that returned `null` and would crash the game on load. Fixed with `RunStats.to_int` (numbers and numeric strings only, else 0) on every field read from the file, plus a test. Garbage, empty, `[]`, `null` and too-new files already fell back to a fresh `Meta` and kept `save.bad.json`. Probe of 10 malformed files: all load.
- **Web:** saves go through `user://` (IndexedDB on the web build), written at career start/end, perk buy and tier pick (file closed each time, so it flushes). If storage is blocked (private window), `FileAccess.open` returns null: `write_meta` returns false, no crash, progress just isn't kept. Not tested on a real browser: please check on your phone once.

## Known issues
- **Human-paced players never reach automation** (0-1%), so tier 2 is effectively an instant-player feature. Reaching it as a human is the main M5 playtest question. Tier 2 `human`/`human_careful` are at median 6 with no gap between them.
- **Twist yardstick still degenerate** (days 1-2 are the only non-twist days; twist days fail 25-54% for `human`). Planned fix: M6-01 (#101).
- `greedy` tier-2 max 26 is close to the cap of 30.
- Headless `ui_check` / tests print benign ObjectDB leak warnings.
